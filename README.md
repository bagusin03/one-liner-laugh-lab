The Sock Defense: a one-line excuse for the make.fun "One-Liner Laugh Lab" bounty. `main.ts` writes a single deadpan excuse — a robot vacuum's legal defense after eating a sock — to `/output/entry.txt`, nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–200 characters, one line) before writing.

> In my defense, the sock entered my dustbin without a warrant — so I ate the evidence.

## Run it

```sh
node main.ts
```
